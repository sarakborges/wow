# Tests

Test projects will cover:

- source format parsers and version detection;
- source-to-runtime ID mapping and provenance;
- normalized schema validation;
- terrain tile stitching and coordinate conversion;
- model skeleton, skin and animation compatibility;
- WotLK spell, aura, resource and cooldown behavior;
- save/load schema migration.

Parser and gameplay tests should run without the Godot editor wherever possible. Engine integration tests should be small and deterministic.
